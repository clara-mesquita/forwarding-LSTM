# Single plots: five models

16 PNG images and 16 PDF versions. Each image contains exactly one chart: one dataset, one context, one metric.

Models: SARIMA, GRU, LSTM, Forwarding LSTM, Transformer. Showing 6 GEANT and 6 RNP links.

User-requested GEANT exclusions: Ankara → Lisboa; LUT → Viena; Lisboa → RESTENA; Anella → Poznań.

Metrics are averaged across seeds per link, using observed test intervals. Kappa is unweighted with fixed 100-Mbit/s classes extending beyond 0–2000; undefined values remain missing. ES–PR has no observed test values.

For each dataset/metric, the two contexts use the same y-axis limits.
